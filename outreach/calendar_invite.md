## Customization Tips

1. **Adjust the technical level** of the description based on the audience:
   - For technical audiences, include more details about the Neo4j backend and knowledge graph capabilities
   - For non-technical audiences, focus on the practical benefits and user-friendly interface

2. **Tailor the schedule** based on the specific focus of each Data Days event:
   - For introductory sessions, allocate more time to basics and demos
   - For advanced sessions, include more hands-on workshop time

3. **Customize the "What to Bring" section** based on the focus area:
   - For imaging-focused sessions: "Bring microscopy data you'd like to organize"
   - For genomics-focused sessions: "Bring sequencing data you'd like to organize"

4. **Add specific prerequisites** if needed:
   - "Please install Docker before the session: [link to instructions]"
   - "Basic familiarity with Python is helpful but not required"

5. **Include department-specific information** when sending to specific groups:
   - "We'll have examples specific to [department] research data"
   - "Previous attendees from [department] found these sessions particularly useful for [specific use case]"
