# Demo Workflows

This directory contains example workflows and tutorials for the Science Data Kit (SDK) used in the Data Days initiative.

## Available Demos

### Data Organization
- [Data Scanning](data_scanning.ipynb) - How to scan and organize research datasets
- [Metadata Extraction](metadata_extraction.ipynb) - Techniques for extracting metadata from various file formats
- [Data Cleaning](data_cleaning.ipynb) - Best practices for cleaning and standardizing research data

### Knowledge Graph
- [Entity Mapping](entity_mapping.ipynb) - Creating entities in the knowledge graph
- [Relationship Modeling](relationship_modeling.ipynb) - Defining relationships between entities
- [Graph Queries](graph_queries.ipynb) - Common Neo4j queries for research data

### Visualization
- [NeoDash Dashboards](neodash_dashboards.ipynb) - Creating interactive dashboards
- [Data Visualization](data_visualization.ipynb) - Visualizing research data and relationships
- [Custom Reports](custom_reports.ipynb) - Generating custom reports from graph data

### Natural Language Interaction
- [Query Generation](query_generation.ipynb) - Using natural language to generate graph queries
- [Data Exploration](data_exploration.ipynb) - Exploring data using natural language commands

## Getting Started

For beginners, we recommend starting with the [Data Scanning](data_scanning.ipynb) demo, followed by [Metadata Extraction](metadata_extraction.ipynb) and [Entity Mapping](entity_mapping.ipynb).
